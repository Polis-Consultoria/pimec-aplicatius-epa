# pimec-aplicatius-epa

JSON de los aplicativos D3 del portal de treball de PIMEC (EPA de Cataluña desde 2005). Los genera y valida la ETL
(`actualitzacio-portal-treball-pimec`, `pimec_etl.epa_aplicatius`); no se editan a mano.

Servidos con GitHub Pages: https://polis-consultoria.github.io/pimec-aplicatius-epa/
